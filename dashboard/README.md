# Planned React Dashboard

**Not yet implemented.** The proposal calls for:
- Owner wallet connection.
- Mock-token balance and vault funding.
- Configuration of agent, merchant allowlist, total budget, per-purchase cap, and expiration.
- Permission revocation and withdrawal controls.
- Current policy and payment history.

Intended stack: React + TypeScript + ethers.js, connected to Anvil.
Use `getCurrentGrant()`, `getVaultBalance()` and contract events for the initial integration.
